# Phase I — Business Process Modeling (working folder)

This folder holds the two PDFs the submission structure requires:

| File | What it is |
| --- | --- |
| `business_process_diagram.pdf` | BPMN / UML activity diagram with swimlanes, exported from the modeling tool |
| `business_process_explanation.pdf` | One page explaining how the process runs and how information moves |

Both are produced by hand: Phase I of the exam is closed to generative AI, so no file here
is machine-written.

## Producing the two files

**Diagram.** Draw it shape by shape in draw.io (https://app.diagrams.net/), Lucidchart or
Canva, keep the editable file in the tool account, then publish it:

1. draw.io: **File → Export as → PDF**, save as
   `docs/business_process/business_process_diagram.pdf`.
2. draw.io: **File → Publish → Link**, access "anyone with the link can view".
3. Open that link in an incognito window before submitting — a screenshot or an exported
   PDF is not a substitute for the published link.

**Explanation.** Two pages style rules are the same as the proposal: Times New Roman 12 pt,
1.15 line spacing, justified, 1-inch margins, headings 13–16 pt bold. Type it in Word, then
**File → Export → Create PDF/XPS** and save as
`docs/business_process/business_process_explanation.pdf`.

Finally paste the tool name and the published link into the
*Phase I – Business Process Modeling* section of the root `README.md`.

## Checklist from the exam sheet

- [ ] One real business process selected and explained (purpose, objectives, expected
      outcome, problem it addresses, why it matters)
- [ ] All actors listed with their responsibilities — users/employees, departments or
      units, external stakeholders, other systems
- [ ] Diagram in swimlanes with start and end events, activities/tasks, decision points
      and alternative paths, sequence and information flows
- [ ] Data activities marked: create, update, retrieve/consult, delete/archive — with a
      short note of what information each one produces or uses
- [ ] One-page explanation written
- [ ] Diagram drawn personally in draw.io / Lucidchart / Canva, kept editable in the
      tool account
- [ ] Diagram published, "anyone with the link can view", link tested in an incognito
      window
- [ ] Both PDFs in `docs/business_process/`
- [ ] Tool name and published link in the root `README.md`
